# Upgrade to Stonefellow v1.3.0 Section 1

1. Upload the deploy ZIP.
2. Extract it over the installed site.
3. Visit `/upgrade.php` as Administrator.
4. Run the pending `1.3.0` personalization migration.
5. Confirm **Database is current**.

The update does not overwrite live database credentials, secrets, catalog/release data, orders, uploads, Knowledge Base data, or runtime storage.
