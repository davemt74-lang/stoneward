# Stonefellow v1.3.4 — Section 5: Richer Track + Release Pages

Stonefellow v1.3 Section 5 turns catalog entries into complete listening and discovery destinations.

## Included
- Rich track hero with track artwork and release-artwork fallback.
- Song story, release context, runtime, year, mood, themes and rights metadata.
- Structured songwriter, composer, producer and recording credits when available.
- Lyrics and recording notes when present.
- Related-track discovery using catalog mood, theme, release and energy context.
- Direct Play, Favorite, Buy Digital, Put It on a Record and Ask About This Song actions.
- Rich release hero with cover art, release notes, credits, release date, runtime and track count.
- Play Release and Buy All Digital Tracks actions.
- Release tracklist links into full track pages and can add individual songs to a custom record.
- Existing cart, persistent player, favorites, Agent and record-builder paths remain authoritative.

## Database
No new schema is required for Section 5. The database target remains **1.3.1**.
