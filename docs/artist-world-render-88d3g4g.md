# Stonefellow 88D3G4G — Visual Timeline and Editorial History

**v1.3.129 · Schema 1.3.63 · Additive migration 054**

G4G extends the existing authenticated Artist World production Studio with a compact **media-lane timeline** and an immutable, edit-by-edit **revision history**. Saved scene, dialogue, and Stonefellow music positions appear as separate-width bars on the same clock. When the current revision has an eligible G4C/G4E EDL, bars use its exact output timing, including independent per-cut overlaps; otherwise they show saved source placement timings. No raw media files, download URLs, thumbnails, or contributor identities are transmitted by the visualization.

Every newly created assembly receives an initial empty version snapshot. Subsequent `sf_assembly_replace` operations atomically archive the immediately preceding revision (including legacy projects that predate G4G) and the newly validated sequence **inside the same database transaction** as the actual clip updates and activity audit. A failed authorization, rights/source-validation conflict, stale revision, audit failure, or transaction rollback cannot create a misleading completed history. Snapshots include only limited editorial metadata (kind, original source identifier, in/out, duration, director notes), and their JSON payloads carry an SHA-256 integrity digest. They are immutable. An existing assembly has **no invented older revisions**: at the next successful edit, the previous revision is backfilled and subsequent snapshots accumulate.

Editors can compare any two existing archived revisions in a private, no-cache GET API: review clip additions, removals, reorderings, exact source time/notes modifications, and total duration changes. Repeated uses of the same source are tracked separately by occurrence. The comparison is a read-only report, **not a restore button**, and has no render/publication side effects. A companion AI Director history displays saved proposal ID, source revision, review status/date, and the revision where an approved reorder was applied. The previous governed AI Composer consent requirements and approval gates remain unchanged.

The implementation relies on existing production-editor permissions, current Admin authentication, optimistic version checks, signed-in sessions, separate licensing and original source-rights certification, private FFmpeg execution, and human review. No browser-exposed media or automatic publishing is added.
