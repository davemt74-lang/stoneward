# Artist World — Stonefellow build direction
Current launch: Section 88A, version 1.3.105.

Artist World is Stonefellow's connected listening, story, collecting, and creation experience, not a separate microsite. Every component uses the existing catalog, Media Library, entitlements, CRM, and Agent Brain.

## 88A: Curated photos in Intelligent Vinyl Studio
- Admin creates a Photo Gallery within Media, attaches cover/photos and publishes the gallery.
- Admin explicitly approves the gallery for vinyl reproduction. This is separate from general download permissions.
- Fans select authorized public high-resolution JPEG/PNG originals for front/back vinyl artwork in the Album Artwork tab.
- Photo source IDs remain canonical Media Library references, not user-controlled external URLs. Both saved drafts and server quotes verify CURRENT gallery approval.
- Original-file integrity and ownership/pressing-license requirements remain protected by existing media production and vinyl licensing gates.
- If a collection is unpublished or approval is withdrawn, it disappears from new selections and new checkout attempts are rejected.

## Direction
- 88B: connected Artist World entities — songs, releases, photos, stories, videos, and shows represented as a coherent navigable map.
- 88C: Living Albums — context, lyrics, recording stories and media synchronized to playback, with consent and publication controls.
- 88D: Collector's Room — owned music, physical media, vinyl printing entitlements, and special editions represented visually.
- 88E: Artist World Agent — one companion that moves among discovery, album experience, collection and vinyl design using existing Agent Brain.
- 88F: world exploration and personalization analytics, strictly privacy/consent gated.

No parallel gallery, second user identity system, or HomeServer changes. Field-level vinyl proof, artwork crop/bleed, and physical production readiness still require specific real-world certification.
